MotionVendi

Episode value = quality × novelty — both measurable from pose streams alone. Labels lie (345 spellings of “washing dishes”), pixels mislead, success labels don’t exist. Motion is the only signal that is universal, cheap, and actually about the behavior.

Pipeline — every stage deletes a lie or a nuisance

GATEteleports, NaN runs, frozen tracker, bad quaternions — corruption out first
QUOTIENThead-frame · arc-length resample · 6D rotation — nuisance deleted, shape remains
KERNELRBF on behavior vectors, PSD-validated — the definition of “same behavior”
VENDIeffective number of distinct behaviors (exp-entropy of kernel spectrum)
CURATEgreedy max-diversity keep-list + most-redundant-first drop ranking

Contributions

  1. Gate-then-measure, quantified. “Clean your data first” turned from folklore into a measured +16% failure mode of diversity metrics.
  2. Arc-length as the speed quotient. Time resampling misses time-warped duplicates (recall 0.00 → 0.75); the invariance is unit-tested.
  3. Size-fair subset ranking. Vendi is bounded by n and non-monotone — subsets compared only via fixed-size bootstraps with CIs.
  4. Falsifiable by design. Planted ground truth; industry-standard metrics (P/R/F1/AUROC, NN-recall@k); honest limitations stated.
  5. Validated on real EgoVerse data. Pipeline surfaced two undocumented quirks (zero-padded array tails; sparse FOV-loss teleports) and detected a known vendor issue (aria orientations) from motion alone.
